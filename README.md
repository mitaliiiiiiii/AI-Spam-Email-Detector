# AI-Spam-Email-Detector
#37

AI Spam Email Detector
.......................................................................................................................................................................

An AI-powered email classification system built with Python and Scikit-learn that identifies whether an email is Spam or Not Spam (Ham) using a Machine Learning model.

🚀 Features
........................................................................................................................................................................
Detects spam emails using Machine Learning
Uses Naive Bayes for text classification
Text preprocessing with CountVectorizer
Interactive command-line interface
Displays prediction confidence score
Easy to retrain with custom datasets
Beginner-friendly and lightweight implementation
🛠️ Tech Stack
............................................................................................................................................................
Python 3
Scikit-learn
CountVectorizer
Multinomial Naive Bayes
📂 Project Structure
.............................................................................................................................................................
spam_detector.py – Main application
requirements.txt – Project dependencies
README.md – Documentation
▶️ How to Run
..............................................................................................................................................................
Clone the repository.
Install dependencies using pip install -r requirements.txt.
Run python spam_detector.py.
Enter email text to classify it as Spam or Ham.
